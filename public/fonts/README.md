# Fontes

A identidade prevê:

- Cabinet Grotesk — principal
- Instrument Serif — editorial

Os arquivos de fonte agora são servidos localmente em WOFF2:

- `cabinet-grotesk-variable.woff2` — obtida pelo CSS oficial do Fontshare;
- `instrument-serif-regular-latin.woff2` — obtida pelo CSS oficial do Google Fonts;
- `instrument-serif-regular-latin-ext.woff2` — obtida pelo CSS oficial do Google Fonts;
- `instrument-serif-italic-latin.woff2` — obtida pelo CSS oficial do Google Fonts;
- `instrument-serif-italic-latin-ext.woff2` — obtida pelo CSS oficial do Google Fonts.

O carregamento está configurado em `styles/fonts.css` com os nomes e pesos
definidos no Brand System.
